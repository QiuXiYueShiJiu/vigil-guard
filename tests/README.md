# 测试

```bash
cd ..            # 到仓库根目录
PYTHONPATH=src python3 -m pytest tests/ -v
```

测试覆盖的重点：

- **渠道渲染**：每种渠道生成的请求体是否符合服务商 API 的实际格式
  （包括阿里云的 HMAC-SHA1 签名、Mailgun 的 form 编码这类容易写错的地方）。
- **不硬编码主机信息**：扫描源码，确认没有 IP、域名、主机名、
  面板路径被写死在代码里。这是本项目的核心约束，必须有测试守住。
- **配置往返**：导出再导入后配置必须一致，且凭据不会出现在普通导出里。
- **状态原子性**：并发写入不会产生半截文件。
- **告警渲染**：HTML 必须转义（防止内容注入），纯文本必须保留结构。
